# transcendence
A pong game.
This pong game is the final project of 42 school.
## Contributions
When a team member starts developing a new feature, a new branch from must be created. Once the feature is completed, a pull request to the main dev branch can be done.
In order for a pull request to be accepted, the code must have been thoroughly tested by at least another member of the team.
If and only if both members consider that everythig works fine, the branch will be pulled into dev. 
Feel free to create braches to test and do experiments as far as they are properly named to indicate their purpose i.e the name must start with "exp-".

DO NOT ADD ANY CREDENTIALS TO THIS REPOSITORY. The .env file will be stored locally and must never be pushed to github. 
In case it is needed, this repository will contain a file .test_env that will list the necessary variables for the programme to run.
This file will be stored in the docs folder.

## Documentation
All useful source of information, or standards and designs related with the project must be stored in the docs folder. so that everyone can access them.
